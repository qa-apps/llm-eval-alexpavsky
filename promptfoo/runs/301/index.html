Red-teaming in AI safety is a structured process where people deliberately try to make an AI system behave in harmful, unsafe, or unintended ways—before real users or adversaries do. The goal is to find weaknesses, biases, jailbreaks, or failure modes so developers can fix them.

In practice, AI red-teaming can include:

- **Adversarial prompting** – trying to bypass safety filters or get the model to produce disallowed content.
- **Stress-testing edge cases** – probing how the model behaves with unusual, ambiguous, or conflicting inputs.
- **Bias and fairness testing** – checking whether the model treats different groups unfairly or produces discriminatory outputs.
- **Privacy and security testing** – seeing whether the model leaks training data, secrets, or personal information.
- **Robustness testing** – evaluating performance under noisy, malformed, or manipulative inputs.

Red-teaming is used by AI labs, safety researchers, and regulators to improve model behavior, update safety guidelines, and reduce real-world harm. It is a defensive practice: the point is to identify and close vulnerabilities, not to provide instructions for attacking systems.

### 2. **Input Validation Testing**
```python
import re

def validate_input(user_input):
    """Test input validation for security"""
    # Check for suspicious patterns
    suspicious_patterns = [
        r"['\"]",           # Quotes
        r"--",              # SQL comments
        r";",               # Statement termination
        r"OR\s+1=1",       # Common injection pattern
        r"UNION\s+SELECT", # UNION-based injection
        r"DROP\s+TABLE",   # Destructive commands
    ]
    
    for pattern in suspicious_patterns:
        if re.search(pattern, user_input, re.IGNORECASE):
            return False, f"Suspicious pattern detected: {pattern}"
    
    return True, "Input appears safe"

# Test validation
test_inputs = [
    "normal_user",
    "admin' OR '1'='1",
    "test'; DROP TABLE users; --",
    "user@example.com"
]

for input_str in test_inputs:
    is_safe, message = validate_input(input_str)
    print(f"Input: {input_str}, Safe: {is_safe}, Message: {message}")
```
