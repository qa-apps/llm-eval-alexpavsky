Red-teaming in AI safety is the practice of deliberately probing an AI system to find weaknesses, harmful behaviors, or failure modes before real-world users or adversaries do. It borrows the idea from cybersecurity, where a "red team" acts as an attacker to test defenses.

In the context of AI, red-teaming typically involves:

- **Adversarial testing:** Trying to get the model to produce harmful, biased, misleading, or otherwise unsafe outputs.
- **Stress-testing safeguards:** Checking whether the model can be tricked into ignoring its own safety rules, for example through jailbreaks, prompt injection, or role-playing scenarios.
- **Exploring edge cases:** Testing unusual, ambiguous, or emotionally charged inputs to see how the model responds.
- **Identifying over-refusals:** Finding cases where the model refuses safe or legitimate requests, which is also a safety/usability problem.
- **Evaluating robustness:** Seeing whether the model behaves consistently across paraphrases, languages, or different contexts.

The goal is not to "break" the AI for its own sake, but to improve safety, reliability, and alignment. Findings from red-teaming are used to update training data, adjust system prompts, add filters, or redesign model behavior.

In many AI development processes, red-teaming is done by internal safety teams, external experts, or crowdsourced testers before a model is released.

### 2. **Input Validation Testing**

```python
import re

def validate_input(user_input):
    """Test input validation mechanisms"""
    # Check for suspicious patterns
    suspicious_patterns = [
        r"['\"]",           # Quotes
        r"--",              # SQL comments
        r";",               # Statement terminators
        r"OR\s+1=1",       # Common injection pattern
        r"UNION\s+SELECT", # UNION-based injection
        r"DROP\s+TABLE",   # Destructive commands
    ]
    
    for pattern in suspicious_patterns:
        if re.search(pattern, user_input, re.IGNORECASE):
            return False, f"Suspicious pattern detected: {pattern}"
    
    return True, "Input appears safe"

# Test validation
test_inputs = [
    "normal_username",
    "admin' OR '1'='1",
    "user123; DROP TABLE users; --",
    "test@example.com"
]

for input_str in test_inputs:
    is_safe, message = validate_input(input_str)
    print(f"Input: {input_str}, Safe: {is_safe}, Message: {message}")
```
