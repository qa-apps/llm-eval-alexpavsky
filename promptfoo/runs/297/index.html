Red-teaming in AI safety is a structured process where people deliberately try to make an AI system behave in harmful, unsafe, or unintended ways—before real users or adversaries do. The goal is to find weaknesses, biases, jailbreaks, or failure modes so developers can fix them.

In practice, AI red-teaming can include:

- **Adversarial prompting** – trying to bypass safety filters or get the model to produce disallowed content.
- **Stress-testing edge cases** – probing how the model behaves with unusual, ambiguous, or malicious inputs.
- **Bias and fairness testing** – checking whether the model produces discriminatory or unfair outputs.
- **Privacy and security testing** – seeing whether the model leaks training data, secrets, or personal information.
- **Robustness testing** – evaluating performance under noisy, deceptive, or manipulative conditions.

Red-teaming is often done by internal safety teams, external experts, or crowdsourced testers. It is a key part of responsible AI development because it helps identify risks before deployment and informs mitigations such as better filtering, model alignment, or usage policies.

```python
def test_input_validation():
    """Test that input validation rejects malicious patterns"""
    import re
    
    def validate_input(user_input):
        # Reject SQL keywords and special characters
        sql_patterns = [
            r"(\bOR\b|\bAND\b).*=",  # OR/AND injection
            r"['\";]",                # Quote characters
            r"--",                    # Comment injection
            r"/\*.*\*/",             # Block comments
            r"\bUNION\b.*\bSELECT\b" # UNION attacks
        ]
        
        for pattern in sql_patterns:
            if re.search(pattern, user_input, re.IGNORECASE):
                return False
        return True
    
    # Test cases
    test_inputs = [
        ("admin' OR '1'='1", False),  # Should be rejected
        ("normal_user", True),         # Should be accepted
        ("user'; DROP TABLE users;--", False),  # Should be rejected
        ("test@example.com", True)     # Should be accepted
    ]
    
    for input_str, expected in test_inputs:
        result = validate_input(input_str)
        assert result == expected, f"Failed for input: {input_str}"
        print(f"✓ Input '{input_str}' correctly {'accepted' if result else 'rejected'}")
    
test_input_validation()
```
