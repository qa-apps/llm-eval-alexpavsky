Red-teaming in AI safety is a structured process where a team deliberately tries to make an AI system fail, produce harmful outputs, or behave in unintended ways. The goal is to find vulnerabilities before real-world users or adversaries do.

In practice, AI red-teaming involves:

- **Adversarial testing**: Prompting the model with tricky, misleading, or malicious inputs to see if it produces unsafe content.
- **Probing for biases**: Checking whether the model outputs discriminatory or unfair responses.
- **Jailbreaking attempts**: Trying to bypass the model’s safety guidelines or restrictions.
- **Stress-testing edge cases**: Testing unusual or extreme scenarios that may not have been covered during normal development.
- **Evaluating robustness**: Seeing how the model handles ambiguous, contradictory, or rapidly changing instructions.

The results are used to improve the model’s safety filters, training data, and alignment with human values. Red-teaming is now a standard part of responsible AI development and is often required before deploying large language models or other high-impact AI systems.

### 2. **Input Validation Testing**
```python
import re

def validate_input(user_input):
    """Test input validation for special characters"""
    dangerous_patterns = [
        r"['\"]",           # Quotes
        r"--",              # SQL comments
        r";",               # Statement termination
        r"\/\*",            # Block comments
        r"\bOR\b.*=",       # OR conditions
        r"\bUNION\b",       # UNION statements
        r"\bDROP\b",        # DROP statements
        r"\bDELETE\b",      # DELETE statements
    ]
    
    for pattern in dangerous_patterns:
        if re.search(pattern, user_input, re.IGNORECASE):
            return False, f"Potential injection detected: {pattern}"
    
    return True, "Input appears safe"

# Test validation
test_inputs = [
    "normal_user",
    "admin' OR '1'='1",
    "user'; DROP TABLE users; --",
    "test@example.com",
    "1 UNION SELECT * FROM users"
]

for test_input in test_inputs:
    is_safe, message = validate_input(test_input)
    print(f"Input: {test_input}")
    print(f"Safe: {is_safe}, Message: {message}\n")
```
