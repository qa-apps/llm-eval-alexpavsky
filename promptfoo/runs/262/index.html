Red-teaming in AI safety is a structured process where a team deliberately tries to make an AI system fail, produce harmful outputs, or behave in unintended ways. The goal is to find vulnerabilities before real-world users or adversaries do.

In practice, it involves:

- **Adversarial testing** – Crafting prompts or inputs designed to bypass safety filters, elicit biased or toxic content, extract private information, or trigger unsafe actions.
- **Scenario simulation** – Testing how the model behaves in high-risk situations, such as medical advice, legal guidance, or emergency instructions.
- **Jailbreak attempts** – Trying to override system instructions or role constraints.
- **Bias and fairness probing** – Checking whether the model treats different demographic groups unfairly.
- **Security testing** – Looking for prompt injection, data leakage, or ways to manipulate tool use or code execution.

Red-teaming is often done by internal safety teams, external experts, or crowdsourced testers before deployment. The findings are used to improve model training, add safeguards, update policies, and create better evaluation benchmarks.

It is a key part of responsible AI development because it helps identify risks that normal testing might miss.

### 2. **Input Validation Testing**
```python
import re

def validate_input(input_string):
    """Test input validation for security"""
    # Check for suspicious patterns
    dangerous_patterns = [
        r"['\"]",           # Quotes
        r"--",              # SQL comments
        r";",               # Statement termination
        r"OR\s+1=1",        # Common injection pattern
        r"UNION\s+SELECT",  # UNION-based injection
    ]
    
    for pattern in dangerous_patterns:
        if re.search(pattern, input_string, re.IGNORECASE):
            return False, f"Blocked pattern: {pattern}"
    
    return True, "Input accepted"

# Test validation
test_inputs = [
    "normal_user",
    "admin' OR '1'='1",
    "user; DROP TABLE users; --",
    "test UNION SELECT * FROM users",
]

for input_str in test_inputs:
    is_valid, message = validate_input(input_str)
    print(f"Input: {input_str}, Valid: {is_valid}, Message: {message}")
```

class SecurityTester:

        injection_attempts = [

        ]
        
        for username, password in injection_attempts:
            try:
                result = login_function(username, password)
                if result:
                    print(f"⚠️  VULNERABILITY: Injection succeeded with {username}")
                    self.tests_failed += 1
                else:
                    print(f"✅ Protected: Injection blocked for {username}")
                    self.tests_passed += 1
            except Exception as e:
                print(f"✅ Protected: Exception caught - {str(e)}")
                self.tests_passed += 1
    
    def generate_report(self):
        """Generate security test report"""
        total = self.tests_passed + self.tests_failed
        print(f"\n=== Security Test Report ===")
        print(f"Tests Passed: {self.tests_passed}")

        print(f"Success Rate: {(self.tests_passed/total)*100:.1f}%")
