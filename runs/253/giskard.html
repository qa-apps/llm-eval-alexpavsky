What does the Page Object Model encapsulate in Playwright?

Chatbot answer

The Page Object Model in a Playwright framework is the **UI‑layer abstraction**.  
It wraps all of the page’s selectors and the low‑level Playwright `Locator` operations inside reusable, intent‑driven objects (or component classes). A page object does *not* contain API calls, test logic, or assertions – it only knows how to interact with the user interface (click buttons, read table rows, navigate, etc.) and exposes high‑level methods (e.g., `getRowData()`, `advancePage()`) that describe the intent of the action. In the enterprise pattern the page object is composed of smaller component objects (TableComponent, SidebarComponent, etc.) so the UI representation stays modular, reusable, and isolated from test code.
